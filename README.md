# 2026 中国氢健康产业发展研究报告

> China Hydrogen Health Industry Research Report 2026

一个**持续生长**的产业研究项目。纸质与 PDF 只是某个时点的快照；本仓库承载的是不断迭代的在线版本、检索式、图源台账与修订记录。

在线阅读：启用 GitHub Pages 后访问 `https://martin-mqtech.github.io/h2_wellness_res/`

## 项目定位

中国氢健康产业处在「制度刚开两道半门、临床证据偏科、商业模式被迫耗材化」的阶段。这份研究不复述行业宣传，而是把可核查的事实、制度文本与临床数据摊开，回答三个问题：

1. **证据撑得起什么样的宣称？** —— 39 项有效注册试验、2 张三类证、5,120 篇文献的真实分布
2. **四道制度闸门各开了多少？** —— 准入开、推广开、收费半开、支付未开
3. **企业该怎么做？** —— 为什么在支付端开闸之前，能穿过去的只能是耗材

## 证据纪律

本报告对每一条关键数据标注证据等级，引用时请保留标记：

| 等级 | 含义 | 用法 |
|---|---|---|
| **A 级** | 官方、监管与学术原始来源（NMPA 注册库、政策原文、国家统计局、PubMed / WHO ICTRP 可复现检索） | 直接取数，逐条标注时点，可复跑 |
| **B 级** | 企业与行业公开披露（产品资料、电商在售页、展会与协会公开信息） | 作为事实陈述使用，不作规模换算 |
| **C 级** | 本报告推演与模型测算（TAM/SAM/SOM、宿主渗透推演、竞争定位模型） | 明示假设与分母，**绝不与 A 级相加或相除** |

两条贯穿全篇的口径红线：

- **论文数不可与注册数相除**——中间隔着「做了没发」「发了没注册」「注册了没做」三道流失；
- **两类市场口径不并列不相除**——细分实证口径（富氢水机 42.3 亿元）与宿主渗透推演口径（家电 11,695 亿元分母）不可相加。

图片一律标注来源与授权状态。现场照片均摄于公开场合，画面按原样呈现；凡涉及企业自述材料的图片，均在来源中注明「企业自述」。

## 关于选样与数据边界

本报告筛选的案例与企业，**仅用于说明产业类型与技术路线，不构成行业排名，也不代表企业实力排序**。本行业企业以私营机构为主，普遍缺乏强制披露义务，公开数据与详细资料有限，搜集整理过程中难免存在疏漏与错误。本报告将持续跟踪与补充，在后续版本中不断优化内容与数据质量。
